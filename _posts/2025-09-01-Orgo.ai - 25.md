| Domain       | Institution / Company                        | Current Approach                                         | Limitation                                                     |
| ------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------- |
| **Academia** | **Dassault Systèmes – Living Heart Project** | HPC/GPU-based cardiac Digital Twin simulations           | High cost & power consumption, not real-time for clinical use  |
|              | **FDA / EMA**                                | Require Digital Twin validation for drug/device approval | Lack of real-time acceleration for regulatory-ready deployment |
| **Industry** | **NVIDIA Clara**                             | Medical imaging + Digital Twin platform, GPU-only        | High power usage, unsuitable for wearables                     |
|              | **Siemens Digital Twin**                     | Industrial/medical modeling & simulation                 | No low-power hardware acceleration                             |
|              | **Apple / Meta / Varjo**                     | On-device physiological modeling (AR/VR)                 | Limited by GPU performance, no ASIC                            |
|              | **Google DeepMind**                          | Cloud-based cardiac Digital Twin research                | No hardware acceleration, cloud-only                           |
|              | **Siemens + Dassault**                       | Digital Twin for pharma/medical via HPC                  | Not hardware-based, no energy-efficient solutions              |
| **Startups** | **Insilico, BioDigital**                     | SaaS / GPU cloud-based Digital Twin services             | No ASIC, no real-time low-power deployment                     |
